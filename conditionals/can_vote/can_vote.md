# Can Vote

Write a program that determines if a person can vote based on their age.

## Examples

**Example 1:**

```
18
```

```
can vote
```

**Example 2:**

```
17
```

```
cannot vote
```

**Example 3:**

```
25
```

```
can vote
```

## Logic

- If `age >= 18`: can vote
- If `age < 18`: cannot vote

## Note

- Voting age is `18` in most countries
- Use the simple comparison operator
- Handle integer ages
