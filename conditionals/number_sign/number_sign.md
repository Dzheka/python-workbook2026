# Number Sign

Write a program that determines if an integer is positive, negative, or zero.

## Examples

**Example 1:**

```
5
```

```
positive
```

**Example 2:**

```
-3
```

```
negative
```

**Example 3:**

```
0
```

```
zero
```

## Logic

- If `n > 0`: positive
- If `n < 0`: negative
- If `n == 0`: zero

## Note

- Handle integer input
- Zero is neither positive nor negative
- Use simple comparison operators
