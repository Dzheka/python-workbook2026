# Exercise: ID Card (Quiz Q9)

Read a first name and a last name with two `input()` calls, then print three
lines:

1. both names in UPPERCASE, separated by one space
2. the initials, each followed by a dot: `initials: B.Q.`
3. the letter counts and their sum: `letters: 6 + 7 = 13`

The names may be typed in any case — `bahrom`, `Bahrom` and `BAHROM` must all
produce the same output.

## Examples

**Example 1:**

```
bahrom
qosimov
```

```
BAHROM QOSIMOV
initials: B.Q.
letters: 6 + 7 = 13
```

**Example 2:**

```
Malika
Rahimova
```

```
MALIKA RAHIMOVA
initials: M.R.
letters: 6 + 8 = 14
```

**Example 3:**

```
ALI
NAZAROV
```

```
ALI NAZAROV
initials: A.N.
letters: 3 + 7 = 10
```
