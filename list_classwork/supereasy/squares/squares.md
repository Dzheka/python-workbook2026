# Squares (Super Easy)

Build a list of numbers with a loop.

## Task

- Create a function `squares(n)` that returns the list of squares from `1` to
  `n`: `[1, 4, 9, ..., n * n]`
- Create a function `list_sum(nums)` that returns the sum of the numbers
  using a `for` loop (do not use `sum`)

## Examples

| Call                  | Returns              |
|-----------------------|----------------------|
| `squares(4)`          | `[1, 4, 9, 16]`      |
| `squares(1)`          | `[1]`                |
| `squares(0)`          | `[]`                 |
| `list_sum([1, 4, 9])` | `14`                 |
| `list_sum([])`        | `0`                  |

Hint: `for i in range(1, n + 1):`.
